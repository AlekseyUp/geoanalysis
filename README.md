# geoanalysis
Проект посвященный геоанализу доступности образовательных услуг, оказываемых учреждениями дополнительного образования Комитета образования и науки города Новокузнецка. 
Интерактивная карта Новокузнецка: Анализ образовательной инфраструктуры
Этот проект представляет собой Python-скрипт для создания интерактивной геоаналитической HTML-карты города Новокузнецка. Скрипт собирает данные из различных источников, обрабатывает их и визуализирует на карте Яндекса, предоставляя информацию о плотности населения и распределении образовательных учреждений по районам.

🚀 Основные возможности
Автоматическая загрузка границ: Скрипт самостоятельно загружает актуальные административные границы районов города из OpenStreetMap (OSM).
Анализ данных из CSV: Читает и обрабатывает данные о школах и учреждениях дополнительного образования (УДО) из локальных CSV-файлов.
Расчет статистики: Автоматически вычисляет ключевые показатели для каждого района:
Площадь
Плотность населения
Количество школ и УДО
Рейтинг обеспеченности УДО на 10 000 жителей.
Интерактивная карта: Генерирует единый yandex_map.html файл, который можно открыть в любом браузере. Карта включает:
Полигоны районов с интерактивной заливкой по плотности населения.
Кластеризованные иконки школ и УДО.
Всплывающие окна (балуны) с подробной информацией о каждом учреждении и возможностью построить маршрут.
Интерактивную легенду и панель со сводной статистикой.
Экспорт отчета: Создает текстовый файл novokuznetsk_statistics.txt со всей рассчитанной статистикой в удобном для чтения формате.

🛠️ Как это работает (Документация)
Процесс создания карты можно разделить на несколько ключевых этапов:
Сбор данных:

osmnx: Эта библиотека отправляет запрос к OpenStreetMap и загружает геометрии (полигоны) всех административных районов Новокузнецка.

pandas / geopandas: Скрипт читает два CSV-файла (Rus_schools_final.csv и УДО.csv), превращая их в гео-таблицы (GeoDataFrames), где каждая строка соответствует точке на карте.

Обработка и анализ:

geopandas: Происходит самая важная "гео-магия". Скрипт выполняет пространственное соединение (sjoin), чтобы определить, в каком районе находится каждая школа и УДО. Также он "лечит" некорректные геометрии, пришедшие из OSM.

geopy: Для каждого УДО вычисляется расстояние до ближайших школ с помощью геодезического расчета, учитывающего кривизну Земли.

pandas: На основе соединенных данных происходит группировка и расчет всей статистики (количество объектов на район, плотность и т.д.).

Генерация результата:

json: Все подготовленные данные (координаты полигонов, списки учреждений, статистика) переводятся в формат JSON. Это универсальный язык, который будет понятен JavaScript-коду на веб-странице.

jinja2: Скрипт берет заранее подготовленный HTML-шаблон, в котором есть специальные метки-заполнители (например, {{ api_key }}). Jinja2 вставляет на место этих меток наши данные в формате JSON.
Финальный HTML-файл: В результате получается готовая HTML-страница, содержащая в себе и разметку, и стили, и все данные, и JavaScript-код для отрисовки карты через API Яндекс.Карт.

📋 Инструкция по запуску

Шаг 1: Подготовка окружения
Установите Python. Если у вас его нет, скачайте с официального сайта python.org. Убедитесь, что при установке вы поставили галочку "Add Python to PATH".
Создайте папку для проекта и скопируйте в нее файл скрипта map_generator.py (или как вы его назвали).
Установите библиотеки. Откройте терминал (командную строку) в папке проекта и выполните следующую команду. Она автоматически установит все необходимые зависимости из файла requirements.txt.

pip install -r requirements.txt

Шаг 2: Подготовка данных
Получите API-ключ для Яндекс.Карт:
Перейдите в Кабинет Разработчика Яндекса.
Войдите в свой аккаунт Яндекса.
Нажмите "Подключить API" -> "JavaScript API и Геокодер".
Заполните простую анкету (можно указать "для личного проекта"). Вы получите ключ вида xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx. Скопируйте его.
Разместите файлы с данными:
В папку проекта поместите два файла:
Rus_schools_final.csv — список школ.
УДО.csv — список учреждений дополнительного образования.

Важно: Файлы должны иметь колонки name, lat, lon (название, широта, долгота).

Шаг 3: Запуск скрипта
Откройте терминал в папке проекта.
Выполните команду:

python map_generator.py

Скрипт задаст вам два вопроса:
Введите ваш API-ключ от Яндекс.Карт: Вставьте ключ, который вы получили на Шаге 2.
Введите процент непрозрачности заливки: Введите число от 0 до 100 (или просто нажмите Enter, чтобы использовать значение по умолчанию).

Шаг 4: Результат
После успешного выполнения в папке проекта появятся два новых файла:
yandex_map.html: Ваша интерактивная карта. Просто откройте этот файл в любом веб-браузере.
novokuznetsk_statistics.txt: Текстовый отчет со всей статистикой по районам.
